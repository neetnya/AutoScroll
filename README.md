# AutoScroll 自动滚轮

一个轻量的 Windows 悬浮面板工具：把面板拖到任意窗口（网页、Telegram 等）上方，即可让该窗口持续自动滚动，无需持续按住任何按键。

## 功能

- **悬浮置顶**：面板始终悬浮在其他窗口之上（Topmost），点击不会抢走目标窗口焦点。
- **持续滚动**：通过 Win32 `SendInput` 向**鼠标指针下方**的窗口注入滚轮事件。
- **智能悬停暂停**：鼠标位于 AutoScroll 面板自身上方时自动暂停注入（点击开始后移开鼠标即开始滚动，中途移回面板调速不会误滚）。
- **全局快捷键**：按 **`Ctrl + Shift + S`** 随时启停滚动，鼠标无需离开正在阅读的窗口（热键被占用时自动静默降级）。
- **速度调节**：40 档均匀可调（1~40 档无重复档位），实时显示毫秒间隔，运行中调速立即生效；支持鼠标滚轮微调滑块。
- **幅度与方向**：20 档单次滚动幅度、↓ 向下 / ↑ 向上方向切换；运行中自动收起设置区并提高透明度减少遮挡。
- **拖拽移动与边界保护**：按住面板空白处拖动即可移动；窗口自动限制在当前显示器工作区内，不会超出屏幕或被任务栏遮挡。
- **记住状态**：速度、幅度、方向和面板位置原子写入 `%AppData%\AutoScroll\settings.json`，下次启动沿用。
- **单实例**：再次启动不会开第二个面板，而是把已有面板拉回当前屏幕。

## 参数说明

### 速度（1~40 档，默认 22）

| 档位 | 间隔 | 说明 |
|------|------|------|
| 1 | 2000 ms | 最慢 |
| 20 | 290 ms | 慢速区间终点（1~21 档每档递减 90 ms） |
| 21 | 200 ms | 快速区间起点 |
| 22 | 192 ms | **默认** |
| 40 | 50 ms | 最快 |

### 幅度（1~20 档，默认 5）

幅度决定**单次滚轮事件的刻度数**（1 刻度 = `WHEEL_DELTA` = 120）。

## 构建与发布

前置条件：已安装 .NET 9 SDK。

```powershell
dotnet build AutoScroll.csproj -c Release
```
