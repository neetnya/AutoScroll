# AutoScroll 自动滚轮

一个轻量的 Windows 悬浮面板工具：把面板拖到任意窗口（网页、Telegram 等）上方，即可让该窗口持续自动滚动，无需任何按键。

## 功能

- **悬浮置顶**：面板始终悬浮在其他窗口之上（Topmost），点击不会抢走目标窗口焦点。
- **持续滚动**：通过 Win32 `SendInput` 向**鼠标指针下方**的窗口注入滚轮事件。
- **启停控制**：点「开始 / 停止」按钮即时启停；运行中面板会收起幅度和方向，并提高透明度，少挡正文。
- **方向切换**：↓ 向下（默认）/ ↑ 向上。
- **速度调节**：40 档，滑块连续可调。
- **幅度调节**：20 档，控制单次滚动的刻度数。
- **拖拽移动**：按住面板空白处拖动即可移动位置；窗口会被限制在当前显示器工作区内。
- **记住状态**：速度、幅度、方向和面板位置写入 `%AppData%\AutoScroll\settings.json`，下次启动沿用。
- **单实例**：再次启动不会开第二个面板，而是把已有面板拉回当前屏幕。
- **退出**：点右上角「✕」按钮关闭程序。

## 使用步骤

1. 双击 `AutoScroll.exe`（或从 `publish\` 目录运行）。
2. 首次出现在屏幕中央（速度 22、幅度 5、方向向下）；之后沿用上次的参数和位置。
3. 把面板拖到方便操作的位置，点「开始」，再把**鼠标指针**移到要滚动的内容上。
4. 滚动打到鼠标所在窗口；用速度滑块随时调节，幅度和方向在停止后展开。
5. 用完点「停止」或直接「✕」退出。

## 参数说明

### 速度（1~40 档，默认 22）

速度档位决定两次滚轮事件之间的**间隔**。档位越大滚动越快：

| 档位 | 间隔 | 说明 |
|------|------|------|
| 1 | 2000 ms | 最慢 |
| 20 | 290 ms | |
| 21 | 200 ms | 旧版速度 1 的中间值 |
| 22 | 192 ms | **默认** |
| 40 | 50 ms | 最快 |

- 档位 1~20：更慢区间，间隔从 2000 ms 线性降到约 200 ms（每档 −90 ms）。
- 档位 21~40：更快区间，间隔从 200 ms 线性降到 50 ms（每档约 −7.9 ms）。

### 幅度（1~20 档，默认 5）

幅度决定**单次滚轮事件的刻度数**。一个刻度 = `WHEEL_DELTA`（120）。幅度越大，单次滚动跳得越远（滚动越「冲」）。

### 方向

- ↓ 向下：内容向下滚动（默认）。
- ↑ 向上：内容向上滚动。

## 技术实现

- **框架**：WPF（.NET 9），目标 `net9.0-windows`。
- **滚动注入**：P/Invoke `user32.dll` 的 `SendInput`，构造 `MOUSEEVENTF_WHEEL`（`dwFlags = 0x0800`）鼠标事件。
- **定时**：`DispatcherTimer` 按速度档位计算的间隔周期触发滚动。
- **方向映射**：Win32 滚轮 delta 正值=内容向上、负值=内容向下，故「向下」用负 delta、「向上」用正 delta。
- **不抢焦点**：扩展样式 `WS_EX_NOACTIVATE`，点击面板时目标窗口保持激活。

## 构建与发布

前置条件：已安装 .NET 9 SDK。

```powershell
# 编译
dotnet build AutoScroll.csproj -c Release

# 发布单文件 exe（64 位，非自包含，依赖系统 .NET 9 运行时）
dotnet publish AutoScroll.csproj -c Release -r win-x64 --self-contained false -o publish
```

发布产物：`publish\AutoScroll.exe`（单文件）。

## 注意事项

- 程序通过**鼠标指针位置**决定滚动目标窗口，滚动期间请把鼠标留在要滚的内容上，不要移到别的窗口。
- 某些应用（游戏、部分自绘控件）可能不响应合成的滚轮事件，属正常现象。
- 需要系统已安装 .NET 9 Desktop Runtime（非自包含发布）。
